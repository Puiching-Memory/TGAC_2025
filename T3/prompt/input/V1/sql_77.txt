# SQL生成任务
## 用户问题
统计：20230123开始7日内元素付费金额
输出：日期（20230123-20230129），人数，元素付费金额
## 涉及表名
`dwd_jordass_currencylog_hi`
## 提示信息
限定：reason in (189, 190)
元素付费类型：imoneytype = 1027
元素付费金额：imoney
## 成功案例参考
以下案例执行成功，可作为参考：
### 成功案例 1
- **SQL ID**: `sql_77`
- **得分**: 1
- **来源**: CKPT `V7.1_22.09_1108`

**SQL:**

```sql
SELECT
    DATE_FORMAT(dteventtime, '%Y%m%d') AS date_id,
    COUNT(DISTINCT vplayerid) AS player_count,
    SUM(imoney) AS total_currency_amount
FROM
    dwd_jordass_currencylog_hi
WHERE
    dteventtime >= '2023-01-23 00:00:00'
    AND dteventtime <= '2023-01-29 23:59:59'
    AND imoneytype = 1027
    AND reason IN (189, 190)
GROUP BY
    DATE_FORMAT(dteventtime, '%Y%m%d')
ORDER BY
    date_id;
```

### 成功案例 2
- **SQL ID**: `sql_77`

**SQL:**

```sql
SELECT 
    substr(tdbank_imp_date, 1, 8) AS date,
    count(distinct vplayerid) AS人数,
    sum(imoney) AS 元素付费金额
FROM dwd_jordass_currencylog_hi
WHERE tdbank_imp_date >= '2023012300'
  AND tdbank_imp_date <= '2023012923'
  AND reason IN (189, 190)
  AND imoneytype = 1027
GROUP BY substr(tdbank_imp_date, 1, 8)
ORDER BY date
```
