# SQL生成任务
## 用户问题
sql_40时间段2024.3.1-2024.6.30分月看用户当月在砺刃的 新进、回流、轻度留存、中度留存、重度留存

输出：月份(202403、...、202406)、新进人数、回流人数、轻度留存人数、中度留存人数、重度留存人数

【任务补充】
新进：当月新进 
回流：上个月未活跃的历史注册用户，在当月活跃
轻度留存：留存用户（上个月活跃，本月也活跃的用户）在本月的活跃度1-4天
中度留存：留存用户（上个月活跃，本月也活跃的用户）在本月的活跃度5-15天
重度留存：留存用户（上个月活跃，本月也活跃的用户）在本月的活跃度16天及以上
