# SQL生成任务
## 用户问题
统计开服至今使用频率最高的用户昵称
2023.07.1200 - 2025071523
输出：昵称（唯一）、人数
## 涉及表名
`dwd_argothek_playerlogin_hi`
## 提示信息
昵称筛选逻辑：
nickname按照#进行划分，取#前半部分的作为nickname
示例：多喝热水#131234 -> 昵称：多喝热水
## 成功案例参考
以下案例执行成功，可作为参考：
### 成功案例 1
- **SQL ID**: `sql_4`
- **得分**: 1
- **来源**: CKPT `V6_31.40_1105`

**SQL:**

```sql
SELECT 
    SPLIT_PART(vrolename, '#', 1) AS nickname,
    COUNT(DISTINCT iuserid) AS user_count
FROM 
    dwd_argothek_playerlogin_hi
WHERE 
    dteventtime >= '2023-07-12 00:00:00'
    AND dteventtime <= '2025-07-15 23:59:59'
GROUP BY 
    SPLIT_PART(vrolename, '#', 1)
ORDER BY 
    user_count DESC
LIMIT 1;
```
