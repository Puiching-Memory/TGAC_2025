# SQL生成任务
## 用户问题
统计2024.1.1～1.3，每天活跃玩家数
输出：统计日期(20240101、20240102、20240103)、玩家数
## 涉及表名
`dws_jordass_login_di`
## 成功案例参考
以下案例执行成功，可作为参考：
### 成功案例 1
- **SQL ID**: `sql_41`
- **得分**: 1
- **来源**: CKPT `V6_31.40_1105`

**SQL:**

```sql
select
    dtstatdate as 统计日期,
    count(distinct vplayerid) as 玩家数
from
    dws_jordass_login_di
where
    dtstatdate between '20240101' and '20240103'
    and platid = 255
group by
    dtstatdate
order by
    dtstatdate;
```
