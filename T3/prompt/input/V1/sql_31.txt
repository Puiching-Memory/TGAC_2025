# SQL生成任务
## 用户问题
统计20250217-20250318协作平台活跃但是没有在协作玩法活跃用户的主玩玩法分布
输出：主玩玩法（传统模式、休闲模式、...、生存模式）、人数
## 涉及表名
`dws_jordass_matchlog_stat_di`, `dwd_jordass_buttonpress_pre_di`, `dws_jordass_mode_roundrecord_di`
## 提示信息
主玩定义：用户累计对局时长最多的玩法；
玩法取 modename in ('传统模式','休闲模式','组队竞技','领地','乐园','广阔天地','创意创作间','生存模式')
协作平台活跃：ugcmbuttonclick中的玩家；
协作玩法活跃：vtemp1='协作'  的玩法记录
## 成功案例参考
以下案例执行成功，可作为参考：
### 成功案例 1
- **SQL ID**: `sql_31`
- **得分**: 1
- **来源**: CKPT `V7.1_22.09_1108`

**SQL:**

```sql
WITH active_players_ugcm AS (
    SELECT DISTINCT vplayerid
    FROM dwd_jordass_buttonpress_pre_di
    WHERE dtstatdate >= '20250217' AND dtstatdate <= '20250318'
),
active_in_collab_mode AS (
    SELECT DISTINCT vplayerid
    FROM dws_jordass_matchlog_stat_di
    WHERE dtstatdate >= '20250217' AND dtstatdate <= '20250318'
      AND vtemp1 = '协作'
),
non_collab_active_players AS (
    SELECT ap.vplayerid
    FROM active_players_ugcm ap
    LEFT JOIN active_in_collab_mode acm ON ap.vplayerid = acm.vplayerid
    WHERE acm.vplayerid IS NULL
),
player_primary_mode AS (
    SELECT 
        vplayerid,
        modename,
        SUM(roundtime) AS total_roundtime,
        ROW_NUMBER() OVER (PARTITION BY vplayerid ORDER BY SUM(roundtime) DESC) AS rn
    FROM dws_jordass_mode_roundrecord_di
    WHERE modename IN ('传统模式','休闲模式','组队竞技','领地','乐园','广阔天地','创意创作间','生存模式')
      AND dtstatdate >= '20250217' AND dtstatdate <= '20250318'
    GROUP BY vplayerid, modename
)
SELECT 
    pmod.modename AS 主玩玩法,
    COUNT(*) AS 人数
FROM non_collab_active_players ncap
JOIN player_primary_mode pmod ON ncap.vplayerid = pmod.vplayerid
WHERE pmod.rn = 1
GROUP BY pmod.modename
ORDER BY 人数 DESC;
```

### 成功案例 2
- **SQL ID**: `sql_31`
- **得分**: 1
- **来源**: CKPT `V6_31.40_1105`

**SQL:**

```sql
WITH platform_active_users AS (
    SELECT DISTINCT vplayerid
    FROM dwd_jordass_buttonpress_pre_di
    WHERE dtstatdate >= '20250217' AND dtstatdate <= '20250318'
),

mode_active_users AS (
    SELECT DISTINCT vplayerid
    FROM dws_jordass_matchlog_stat_di
    WHERE dtstatdate >= '20250217' AND dtstatdate <= '20250318'
    AND vtemp1 = '协作'
),

qualified_users AS (
    SELECT p.vplayerid
    FROM platform_active_users p
    WHERE p.vplayerid NOT IN (SELECT vplayerid FROM mode_active_users)
),

user_total_time_by_mode AS (
    SELECT 
        r.vplayerid,
        r.modename,
        SUM(r.roundtime) as total_time
    FROM dws_jordass_mode_roundrecord_di r
    INNER JOIN qualified_users q ON r.vplayerid = q.vplayerid
    WHERE r.dtstatdate >= '20250217' AND r.dtstatdate <= '20250318'
    AND r.modename IN ('传统模式','休闲模式','组队竞技','领地','乐园','广阔天地','创意创作间','生存模式')
    GROUP BY r.vplayerid, r.modename
),

user_primary_mode AS (
    SELECT 
        vplayerid,
        modename,
        total_time,
        ROW_NUMBER() OVER (PARTITION BY vplayerid ORDER BY total_time DESC) as rn
    FROM user_total_time_by_mode
),

primary_modes AS (
    SELECT 
        modename,
        COUNT(*) as user_count
    FROM user_primary_mode
    WHERE rn = 1
    GROUP BY modename
)

SELECT 
    modename as 主玩玩法,
    user_count as 人数
FROM primary_modes
ORDER BY user_count DESC;
```
