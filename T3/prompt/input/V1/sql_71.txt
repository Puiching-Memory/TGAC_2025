# SQL生成任务
## 用户问题
统计2024.11.29-2024.12.19期间，每七天统计一次阶梯活动相关用户数
输出 日期范围（20241129-20241205、20241206-20241212、20241213-20241219），extarg1类型，用户数，次数
## 涉及表名
`dwd_jordass_activitypress_hi`
## 提示信息
阶梯活动：ireason = 2411291018 and buttontype = 10045 and extarg1 in (101,109,110)
## 成功案例参考
以下案例执行成功，可作为参考：
### 成功案例 1
- **SQL ID**: `sql_71`
- **得分**: 1
- **来源**: CKPT `V7.1_22.09_1108`

**SQL:**

```sql
SELECT 
    CASE 
        WHEN dteventtime >= '2024-11-29' AND dteventtime < '2024-12-06' THEN '20241129-20241205'
        WHEN dteventtime >= '2024-12-06' AND dteventtime < '2024-12-13' THEN '20241206-20241212'
        WHEN dteventtime >= '2024-12-13' AND dteventtime <= '2024-12-19' THEN '20241213-20241219'
    END AS date_range,
    extarg1,
    COUNT(DISTINCT vplayerid) AS user_count,
    COUNT(*) AS event_count
FROM dwd_jordass_activitypress_hi
WHERE 
    dteventtime >= '2024-11-29' AND dteventtime <= '2024-12-19'
    AND ireason = 2411291018 
    AND buttontype = 10045 
    AND extarg1 IN (101, 109, 110)
GROUP BY 
    date_range, 
    extarg1
ORDER BY 
    date_range, 
    extarg1;
```

WITH date_ranges AS (

  UNION ALL
  SELECT '20241206', '20241212'
  UNION ALL
  SELECT '20241213', '20241219'
),
filtered_data AS (
  SELECT 
    SUBSTRING(tdbank_imp_date, 1, 8) as date_part,
    vplayerid,
    extarg1,
    CASE 
      WHEN SUBSTRING(tdbank_imp_date, 1, 8) >= '20241129' AND SUBSTRING(tdbank_imp_date, 1, 8) <= '20241205' THEN '20241129-20241205'
      WHEN SUBSTRING(tdbank_imp_date, 1, 8) >= '20241206' AND SUBSTRING(tdbank_imp_date, 1, 8) <= '20241212' THEN '20241206-20241212'
      WHEN SUBSTRING(tdbank_imp_date, 1, 8) >= '20241213' AND SUBSTRING(tdbank_imp_date, 1, 8) <= '20241219' THEN '20241213-20241219'
    END as date_range
  FROM dwd_jordass_activitypress_hi
  WHERE ireason = 2411291018 
    AND buttontype = 10045 
    AND extarg1 IN (101, 109, 110)
    AND SUBSTRING(tdbank_imp_date, 1, 8) >= '20241129' 
    AND SUBSTRING(tdbank_imp_date, 1, 8) <= '20241219'
)
SELECT 
  date_range as '日期范围',
  extarg1 as 'extarg1类型',
  COUNT(DISTINCT vplayerid) as '用户数',
  COUNT(*) as '次数'

GROUP BY date_range, extarg1
ORDER BY date_range, extarg1
