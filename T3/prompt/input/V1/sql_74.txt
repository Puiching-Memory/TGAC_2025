# SQL生成任务
## 用户问题
统计 SS30赛季手册和SS29赛季手册的按钮人数
SS30赛季:2024112305 - 2024112616
SS29赛季:2024092405 - 2024092716
输出：按钮类型，SS30赛季手册人数，SS29赛季手册人数
## 涉及表名
`dwd_jordass_pressbutton_hi`
## 提示信息
按钮：buttontypes等于411130或411200
## 成功案例参考
以下案例执行成功，可作为参考：
### 成功案例 1
- **SQL ID**: `sql_74`
- **得分**: 1
- **来源**: CKPT `V6.2_33.72_1109`

**SQL:**

```sql
SELECT 
    '411130' AS button_type,
    COUNT(DISTINCT CASE WHEN tdbank_imp_date >= '2024112305' AND tdbank_imp_date <= '2024112616' AND (buttontypes = '411130' OR buttontypes LIKE '411130;%' OR buttontypes LIKE '%;411130' OR buttontypes LIKE '%;411130;%') THEN vplayerid END) AS SS30_season_manual_users,
    COUNT(DISTINCT CASE WHEN tdbank_imp_date >= '2024092405' AND tdbank_imp_date <= '2024092716' AND (buttontypes = '411130' OR buttontypes LIKE '411130;%' OR buttontypes LIKE '%;411130' OR buttontypes LIKE '%;411130;%') THEN vplayerid END) AS SS29_season_manual_users
FROM dwd_jordass_pressbutton_hi
WHERE (buttontypes = '411130' OR buttontypes LIKE '411130;%' OR buttontypes LIKE '%;411130' OR buttontypes LIKE '%;411130;%')

UNION ALL

SELECT 
    '411200' AS button_type,
    COUNT(DISTINCT CASE WHEN tdbank_imp_date >= '2024112305' AND tdbank_imp_date <= '2024112616' AND (buttontypes = '411200' OR buttontypes LIKE '411200;%' OR buttontypes LIKE '%;411200' OR buttontypes LIKE '%;411200;%') THEN vplayerid END) AS SS30_season_manual_users,
    COUNT(DISTINCT CASE WHEN tdbank_imp_date >= '2024092405' AND tdbank_imp_date <= '2024092716' AND (buttontypes = '411200' OR buttontypes LIKE '411200;%' OR buttontypes LIKE '%;411200' OR buttontypes LIKE '%;411200;%') THEN vplayerid END) AS SS29_season_manual_users
FROM dwd_jordass_pressbutton_hi
WHERE (buttontypes = '411200' OR buttontypes LIKE '411200;%' OR buttontypes LIKE '%;411200' OR buttontypes LIKE '%;411200;%')
```
