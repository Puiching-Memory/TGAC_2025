# SQL生成任务
## 用户问题
查询2024.11.29-2024.12.19期间的任务领取数据，并按类型汇总（跨日期）
输出 ：日期（YYYYMMDD、汇总），类型，人数，次数
## 涉及表名
`dwd_jordass_activity_rewardrecord_hi`
## 提示信息
任务领取：actid = 2411291018and acttype = 10045 and awardidx in (1, 2, 3)，一条记录代表领取一次
## 成功案例参考
以下案例执行成功，可作为参考：
### 成功案例 1
- **SQL ID**: `sql_65`
- **得分**: 1
- **来源**: CKPT `V7.1_22.09_1108`

**SQL:**

```sql
SELECT 
    REPLACE(SUBSTR(dteventtime, 1, 10), '-', '') AS event_date,
    awardidx AS type,
    COUNT(DISTINCT vplayerid) AS people_count,
    COUNT(*) AS record_count
FROM dwd_jordass_activity_rewardrecord_hi
WHERE actid = 2411291018 
    AND acttype = 10045 
    AND awardidx IN (1, 2, 3)
    AND dteventtime >= '2024-11-29 00:00:00'
    AND dteventtime < '2024-12-20 00:00:00'
GROUP BY REPLACE(SUBSTR(dteventtime, 1, 10), '-', ''), awardidx

UNION ALL

SELECT 
    '汇总' AS event_date,
    awardidx AS type,
    COUNT(DISTINCT vplayerid) AS people_count,
    COUNT(*) AS record_count
FROM dwd_jordass_activity_rewardrecord_hi
WHERE actid = 2411291018 
    AND acttype = 10045 
    AND awardidx IN (1, 2, 3)
    AND dteventtime >= '2024-11-29 00:00:00'
    AND dteventtime < '2024-12-20 00:00:00'
GROUP BY awardidx
ORDER BY event_date, type
```
