# SQL生成任务
## 用户问题
统计2018年注册且近30天有活跃用户，并且在2020年9月到22年4月期间添加过好友的用户，每个月人均在线好友数
输出：自然月（YYYYMM），人均在线好友数
## 涉及表名
`dws_jordass_login_df`, `dwd_jordass_playerlogin_hi`, `dwd_jordass_friendlist_hi`
## 提示信息
添加过好友：type=2
