# SQL生成任务
## 用户问题
2025年4月29日，2025年6月1日这两天
在后续半个月未登录用户，在后续半个月有登录用户：
输出：统计日期（yyyymmdd）,用户类型（后续半个月未登录，后续半个月有登录，新增、7日以内留存（不含当天的前七日后面同理）、7~14日回流、14~30日回流、30~90日回流、90日以上回流的用户量级），人数
## 涉及表名
`dws_jordass_login_df`, `dws_jordass_login_di`
