# SQL生成任务
## 用户问题
统计2025.1.1-2025.1.31期间活跃度分布
输出：活跃度（轻度、中度、重度）、玩家数

活跃度：轻度1-5天，中度6-15天，重度大于16天
## 涉及表名
`dws_jordass_login_di`
## 成功案例参考
以下案例执行成功，可作为参考：
### 成功案例 1
- **SQL ID**: `sql_43`
- **得分**: 1
- **来源**: CKPT `V7.1_22.09_1108`

**SQL:**

```sql
SELECT
    CASE
        WHEN login_days BETWEEN 1 AND 5 THEN '轻度'
        WHEN login_days BETWEEN 6 AND 15 THEN '中度'
        WHEN login_days >= 16 THEN '重度'
    END AS 活跃度,
    COUNT(*) AS 玩家数
FROM (
    SELECT
        vplayerid,
        COUNT(DISTINCT dtstatdate) AS login_days
    FROM dws_jordass_login_di
    WHERE dtstatdate >= '20250101' AND dtstatdate <= '20250131'
    GROUP BY vplayerid
) t
GROUP BY
    CASE
        WHEN login_days BETWEEN 1 AND 5 THEN '轻度'
        WHEN login_days BETWEEN 6 AND 15 THEN '中度'
        WHEN login_days >= 16 THEN '重度'
    END
ORDER BY FIELD(活跃度, '轻度', '中度', '重度')
```

### 成功案例 2
- **SQL ID**: `sql_43`
- **得分**: 1
- **来源**: CKPT `V6_31.40_1105`

**SQL:**

```sql
with player_login_days as (
  select
    vplayerid,
    count(distinct dtstatdate) as login_days
  from
    dws_jordass_login_di
  where
    dtstatdate between '20250101' and '20250131'
    and platid = 255
  group by
    vplayerid
),
player_activity_level as (
  select
    vplayerid,
    case
      when login_days between 1 and 5 then '轻度'
      when login_days between 6 and 15 then '中度'
      when login_days >= 16 then '重度'
    end as 活跃度
  from
    player_login_days
)
select
  活跃度,
  count(vplayerid) as 玩家数
from
  player_activity_level
where
  活跃度 is not null
group by
  活跃度
order by
  field(活跃度, '轻度', '中度', '重度');
```
