# SQL生成任务
## 用户问题
统计2023.07.02和2023.07.09 参与乐园各子玩法的用户里，砺刃新进、回流、留存用户数
注：新进，回流，留存都按照7天为一个周期来计算
输出：统计日期（YYYYMMDD），玩法，类型（新进、回流、留存），人数

【任务补充】
乐园玩法子用户筛选条件：
instr(substr(cbitmap,1,7),'1')>0
回流与留存计算：
case when datediff(dtstatdate,dregdate)<=6 then '新进'
when instr(substr(cbitmap,8,7),'1')>0 then '留存'
when instr(substr(cbitmap,8,7),'1')=0 then '回流'
注意只需要统计上述三种类型
