# SQL生成任务
## 用户问题
统计2025.9.1到9.10每天productid的参与直购购买人数，直购购买金额以及数量，当天注册人数
输出：统计日期(yyyymmdd),productid,直购购买人数,直购购买金额,直购购买数量
## 涉及表名
`dws_jordass_login_df`, `dwd_jordass_directpaycommflow_hi`
## 提示信息
productid的参与直购：op='take' and opres='ok'
	and productid in ('package_6','package_18','outfit_pack','weapon_pack')
## 成功案例参考
以下案例执行成功，可作为参考：
### 成功案例 1
- **SQL ID**: `sql_103`
- **得分**: 1
- **来源**: CKPT `V6.2_33.72_1109`

**SQL:**

```sql
SELECT 
    DATE_FORMAT(STR_TO_DATE(dteventtime, '%Y-%m-%d %H:%i:%s'), '%Y%m%d') AS 统计日期,
    productid AS productid,
    COUNT(DISTINCT vplayerid) AS 直购购买人数,
    SUM(money) AS 直购购买金额,
    SUM(goodsnum) AS 直购购买数量
FROM dwd_jordass_directpaycommflow_hi
WHERE DATE_FORMAT(STR_TO_DATE(dteventtime, '%Y-%m-%d %H:%i:%s'), '%Y-%m-%d') BETWEEN '2025-09-01' AND '2025-09-10'
    AND op = 'take' 
    AND opres = 'ok'
    AND productid IN ('package_6', 'package_18', 'outfit_pack', 'weapon_pack')
GROUP BY 
    DATE_FORMAT(STR_TO_DATE(dteventtime, '%Y-%m-%d %H:%i:%s'), '%Y%m%d'),
    productid
ORDER BY 
    统计日期, 
    productid
```
