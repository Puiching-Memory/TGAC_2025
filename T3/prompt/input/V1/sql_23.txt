# SQL生成任务
## 用户问题
统计2025年3月24日至2025年3月30日，至少完成过一场对局，且渠道登录的用户qq
输出:qq
## 涉及表名
`dws_argothek_oss_login_di`, `dim_argothek_gplayerid2qqwxid_df`, `dwd_argothek_playermatchstats_hi`, `dim_argothek_gplayerid_vroleid_df`
## 提示信息
渠道筛选条件：iloginway = 3
用户ID筛选swxid_type = "qq" -- 筛选swxid_type为"qq"
## 成功案例参考
以下案例执行成功，可作为参考：
### 成功案例 1
- **SQL ID**: `sql_23`
- **得分**: 1
- **来源**: CKPT `V6_31.40_1105`

**SQL:**

```sql
SELECT DISTINCT t2.suserid AS qq
FROM dwd_argothek_playermatchstats_hi t1
JOIN dim_argothek_gplayerid_vroleid_df t3
  ON t1.vroleid = t3.vRoleID
  AND t3.dtstatdate = '20250330' -- 使用周期最后一天的维度数据
JOIN dim_argothek_gplayerid2qqwxid_df t2
  ON t3.iuserid = t2.iuserid
  AND t2.dtstatdate = '20250330'
  AND t2.swxid_type = 'qq'
JOIN dws_argothek_oss_login_di t4
  ON t2.iuserid = t4.iuserid
  AND t4.statis_date BETWEEN 20250324 AND 20250330
  AND t4.iloginway = 3
WHERE t1.dteventtime >= '2025-03-24 00:00:00'
  AND t1.dteventtime < '2025-03-31 00:00:00'
  AND t1.isplayercompleted = 1;
```
