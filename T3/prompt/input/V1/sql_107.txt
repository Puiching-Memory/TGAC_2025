# SQL生成任务
## 用户问题
统计2022.1.18-1.24与2021.10.19-12.20这两个时间段
 buttontype =99123并且 ireason=3的人数，以及两个时间段都满足条件的交叉人数
输出：2022.1.18-1.24人数，2021.10.19-12.20人数，两个时间段交叉的人数
## 涉及表名
`dwd_jordass_activitypress_hi`
## 成功案例参考
以下案例执行成功，可作为参考：
### 成功案例 1
- **SQL ID**: `sql_107`
- **得分**: 1
- **来源**: CKPT `V7.1_22.09_1108`

**SQL:**

```sql
SELECT
    COUNT(DISTINCT CASE WHEN dteventtime >= '2022-01-18 00:00:00' AND dteventtime <= '2022-01-24 23:59:59' AND buttontype = 99123 AND ireason = 3 THEN vplayerid END) AS count_2022_week,
    COUNT(DISTINCT CASE WHEN dteventtime >= '2021-10-19 00:00:00' AND dteventtime <= '2021-12-20 23:59:59' AND buttontype = 99123 AND ireason = 3 THEN vplayerid END) AS count_2021_period,
    COUNT(DISTINCT CASE 
        WHEN dteventtime >= '2022-01-18 00:00:00' AND dteventtime <= '2022-01-24 23:59:59' AND buttontype = 99123 AND ireason = 3 
             AND vplayerid IN (
                 SELECT DISTINCT vplayerid 
                 FROM dwd_jordass_activitypress_hi 
                 WHERE dteventtime >= '2021-10-19 00:00:00' AND dteventtime <= '2021-12-20 23:59:59' 
                   AND buttontype = 99123 AND ireason = 3
             )
        THEN vplayerid 
    END) AS count_intersection
FROM dwd_jordass_activitypress_hi
WHERE
    (dteventtime >= '2022-01-18 00:00:00' AND dteventtime <= '2022-01-24 23:59:59')
    OR (dteventtime >= '2021-10-19 00:00:00' AND dteventtime <= '2021-12-20 23:59:59')
```

### 成功案例 2
- **SQL ID**: `sql_107`
- **得分**: 1
- **来源**: CKPT `V6_31.40_1105`

**SQL:**

```sql
WITH period1_users AS (
  SELECT DISTINCT vplayerid as uin
  FROM dwd_jordass_activitypress_hi
  WHERE tdbank_imp_date >= '2022011800' AND tdbank_imp_date <= '2022012423'
    AND buttontype = 99123
    AND ireason = 3
),
period2_users AS (
  SELECT DISTINCT vplayerid as uin
  FROM dwd_jordass_activitypress_hi
  WHERE tdbank_imp_date >= '2021101900' AND tdbank_imp_date <= '2021122023'
    AND buttontype = 99123
    AND ireason = 3
)
SELECT 
  (SELECT COUNT(*) FROM period1_users) AS period1_count,
  (SELECT COUNT(*) FROM period2_users) AS period2_count,
  (SELECT COUNT(*) 
   FROM period1_users p1
   INNER JOIN period2_users p2 ON p1.uin = p2.uin) AS intersection_count
```
