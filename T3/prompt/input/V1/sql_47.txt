# SQL生成任务
## 用户问题
统计2023.07.01-08.31期间，每天微信活跃用户在2023.09.1-09.21期间流失并且是2023.07.01-08.31有付费的用户
输出：人数
## 涉及表名
`dws_jordass_water_di`, `dws_jordass_login_di`
## 成功案例参考
以下案例执行成功，可作为参考：
### 成功案例 1
- **SQL ID**: `sql_47`
- **得分**: 1
- **来源**: CKPT `V7.1_22.09_1108`

**SQL:**

```sql
WITH active_paying_users AS (
  SELECT DISTINCT l.vplayerid
  FROM dws_jordass_login_di l
  INNER JOIN dws_jordass_water_di w ON l.vplayerid = w.vplayerid AND l.dtstatdate = w.dtstatdate
  WHERE l.vgameappid = 'wx'
    AND w.vgameappid = 'wx'
    AND l.dtstatdate BETWEEN '20230701' AND '20230831'
    AND w.iamount > 0
),
lost_users AS (
  SELECT vplayerid
  FROM active_paying_users
  WHERE vplayerid NOT IN (
    SELECT DISTINCT vplayerid
    FROM dws_jordass_login_di
    WHERE dtstatdate BETWEEN '20230901' AND '20230921'
      AND vgameappid = 'wx'
  )
)
SELECT COUNT(*) AS lost_user_count
FROM lost_users;
```

### 成功案例 2
- **SQL ID**: `sql_47`
- **得分**: 1
- **来源**: CKPT `V6_31.40_1105`

**SQL:**

```sql
WITH active_users_in_period AS (
    SELECT DISTINCT vplayerid
    FROM dws_jordass_login_di
    WHERE dtstatdate >= '20230701' AND dtstatdate <= '20230831'
      AND vgameappid = 'wx'
),

paid_users_in_period AS (
    SELECT DISTINCT vplayerid
    FROM dws_jordass_water_di
    WHERE dtstatdate >= '20230701' AND dtstatdate <= '20230831'
),

流失_user AS (
    SELECT DISTINCT a.vplayerid
    FROM active_users_in_period a
    INNER JOIN paid_users_in_period p ON a.vplayerid = p.vplayerid
    WHERE a.vplayerid NOT IN (
        SELECT DISTINCT vplayerid
        FROM dws_jordass_login_di
        WHERE dtstatdate >= '20230901' AND dtstatdate <= '20230921'
    )
)

SELECT COUNT(DISTINCT vplayerid) AS 人数
FROM 流失_user;
```
