# SQL生成任务
## 用户问题
统计20220413-20220421全平台每天活跃的次留，3留，7留情况（分活动和登录）
输出：统计日期(yyyymmdd),活动人数，登录次留，登录3留，登录7留，活动次留，活动3留，活动7留
## 涉及表名
`dws_jordass_login_di`, `dwd_jordass_activity_rewardrecord_hi`
## 提示信息
活动:actid = 2201123904
## 失败案例参考
以下案例曾出现过错误，请避免类似问题：
### 失败案例 1
- **SQL ID**: `sql_110`
- **来源**: CKPT `V7.1_22.09_1108`

**错误SQL:**

```sql
WITH login_base AS (
    SELECT 
        dtstatdate,
        vplayerid
    FROM dws_jordass_login_di 
    WHERE dtstatdate BETWEEN '20220413' AND '20220421'
    GROUP BY dtstatdate, vplayerid
),
activity_base AS (
    SELECT 
        LEFT(tdbank_imp_date, 8) AS activity_date,
        vplayerid
    FROM dwd_jordass_activity_rewardrecord_hi 
    WHERE actid = 2201123904 
      AND LEFT(tdbank_imp_date, 8) BETWEEN '20220413' AND '20220421'
    GROUP BY LEFT(tdbank_imp_date, 8), vplayerid
),
login_retention AS (
    SELECT 
        l1.dtstatdate AS stat_date,
        COUNT(DISTINCT l1.vplayerid) AS login_dau,
        COUNT(DISTINCT l2.vplayerid) AS login_d1,
        COUNT(DISTINCT l3.vplayerid) AS login_d3,
        COUNT(DISTINCT l7.vplayerid) AS login_d7
    FROM login_base l1
    LEFT JOIN login_base l2 ON l1.vplayerid = l2.vplayerid AND l2.dtstatdate = DATE_FORMAT(DATE_ADD(CAST(CONCAT(SUBSTR(l1.dtstatdate,1,4),'-',SUBSTR(l1.dtstatdate,5,2),'-',SUBSTR(l1.dtstatdate,7,2)) AS DATE), INTERVAL 1 DAY), '%Y%m%d')
    LEFT JOIN login_base l3 ON l1.vplayerid = l3.vplayerid AND l3.dtstatdate = DATE_FORMAT(DATE_ADD(CAST(CONCAT(SUBSTR(l1.dtstatdate,1,4),'-',SUBSTR(l1.dtstatdate,5,2),'-',SUBSTR(l1.dtstatdate,7,2)) AS DATE), INTERVAL 3 DAY), '%Y%m%d')
    LEFT JOIN login_base l7 ON l1.vplayerid = l7.vplayerid AND l7.dtstatdate = DATE_FORMAT(DATE_ADD(CAST(CONCAT(SUBSTR(l1.dtstatdate,1,4),'-',SUBSTR(l1.dtstatdate,5,2),'-',SUBSTR(l1.dtstatdate,7,2)) AS DATE), INTERVAL 7 DAY), '%Y%m%d')
    GROUP BY l1.dtstatdate
),
activity_retention AS (
    SELECT 
        a1.activity_date AS stat_date,
        COUNT(DISTINCT a1.vplayerid) AS activity_dau,
        COUNT(DISTINCT a2.vplayerid) AS activity_d1,
        COUNT(DISTINCT a3.vplayerid) AS activity_d3,
        COUNT(DISTINCT a7.vplayerid) AS activity_d7
    FROM activity_base a1
    LEFT JOIN activity_base a2 ON a1.vplayerid = a2.vplayerid AND a2.activity_date = DATE_FORMAT(DATE_ADD(CAST(CONCAT(SUBSTR(a1.activity_date,1,4),'-',SUBSTR(a1.activity_date,5,2),'-',SUBSTR(a1.activity_date,7,2)) AS DATE), INTERVAL 1 DAY), '%Y%m%d')
    LEFT JOIN activity_base a3 ON a1.vplayerid = a3.vplayerid AND a3.activity_date = DATE_FORMAT(DATE_ADD(CAST(CONCAT(SUBSTR(a1.activity_date,1,4),'-',SUBSTR(a1.activity_date,5,2),'-',SUBSTR(a1.activity_date,7,2)) AS DATE), INTERVAL 3 DAY), '%Y%m%d')
    LEFT JOIN activity_base a7 ON a1.vplayerid = a7.vplayerid AND a7.activity_date = DATE_FORMAT(DATE_ADD(CAST(CONCAT(SUBSTR(a1.activity_date,1,4),'-',SUBSTR(a1.activity_date,5,2),'-',SUBSTR(a1.activity_date,7,2)) AS DATE), INTERVAL 7 DAY), '%Y%m%d')
    GROUP BY a1.activity_date
)
SELECT 
    lr.stat_date AS 统计日期,
    ar.activity_dau AS 活动人数,
    lr.login_d1 AS 登录次留,
    lr.login_d3 AS 登录3留,
    lr.login_d7 AS 登录7留,
    ar.activity_d1 AS 活动次留,
    ar.activity_d3 AS 活动3留,
    ar.activity_d7 AS 活动7留
FROM login_retention lr
JOIN activity_retention ar ON lr.stat_date = ar.stat_date
ORDER BY lr.stat_date
```

> **错误原因**: 结果与预期不匹配
