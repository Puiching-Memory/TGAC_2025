# SQL生成任务
## 用户问题
在2023.7.19-2023.7.25时间范围内，分别统计参与了隐匿的用户人数、既参与隐匿也参与了桥梁争夺的用户、既参与隐匿也参与了隐匿模式的用户
输出：参与了隐匿的不重复的人的个数、参与隐匿并且参与了桥梁争夺的不重复的人的个数、参与隐匿并且参与了隐匿模式的不重复的人的个数

## 涉及表名
`dws_jordass_matchlog_stat_di`, `dws_jordass_mode_roundrecord_di`
## 提示信息
隐匿的用户：imode = 1307095884553538304  and platid <> 255
桥梁争夺的用户：imode = 1310822585431254784  and platid <> 255
隐匿模式的用户：mode=2370
## 成功案例参考
以下案例执行成功，可作为参考：
### 成功案例 1
- **SQL ID**: `sql_97`
- **得分**: 1
- **来源**: CKPT `V7.1_22.09_1108`

**SQL:**

```sql
SELECT
    COUNT(DISTINCT ml.vplayerid) AS hidden_participants,
    COUNT(DISTINCT CASE WHEN br.vplayerid IS NOT NULL THEN ml.vplayerid END) AS hidden_and_bridge_count,
    COUNT(DISTINCT CASE WHEN hm.vplayerid IS NOT NULL THEN ml.vplayerid END) AS hidden_and_mode_count
FROM
    dws_jordass_matchlog_stat_di ml
    LEFT JOIN (
        SELECT DISTINCT vplayerid
        FROM dws_jordass_matchlog_stat_di
        WHERE imode = 1310822585431254784 AND platid <> 255
          AND SUBSTR(dtstatdate, 1, 4) = '2023'
          AND CAST(SUBSTR(dtstatdate, 5, 2) AS INT) = 7
          AND CAST(SUBSTR(dtstatdate, 7, 2) AS INT) BETWEEN 19 AND 25
    ) br ON ml.vplayerid = br.vplayerid
    LEFT JOIN (
        SELECT DISTINCT vplayerid
        FROM dws_jordass_mode_roundrecord_di
        WHERE mode = 2370
          AND SUBSTR(dtstatdate, 1, 4) = '2023'
          AND CAST(SUBSTR(dtstatdate, 5, 2) AS INT) = 7
          AND CAST(SUBSTR(dtstatdate, 7, 2) AS INT) BETWEEN 19 AND 25
    ) hm ON ml.vplayerid = hm.vplayerid
WHERE
    ml.imode = 1307095884553538304
    AND ml.platid <> 255
    AND SUBSTR(ml.dtstatdate, 1, 4) = '2023'
    AND CAST(SUBSTR(ml.dtstatdate, 5, 2) AS INT) = 7
    AND CAST(SUBSTR(ml.dtstatdate, 7, 2) AS INT) BETWEEN 19 AND 25;
```

### 成功案例 2
- **SQL ID**: `sql_97`
- **得分**: 1
- **来源**: CKPT `V6_31.40_1105`

**SQL:**

```sql
WITH yinmi_users AS (
  SELECT DISTINCT vplayerid
  FROM dws_jordass_matchlog_stat_di
  WHERE dtstatdate BETWEEN '20230719' AND '20230725'
    AND imode = 1307095884553538304
    AND platid <> 255
),
qiaoliang_users AS (
  SELECT DISTINCT vplayerid
  FROM dws_jordass_matchlog_stat_di
  WHERE dtstatdate BETWEEN '20230719' AND '20230725'
    AND imode = 1310822585431254784
    AND platid <> 255
),
yinmi_mode_users AS (
  SELECT DISTINCT vplayerid
  FROM dws_jordass_mode_roundrecord_di
  WHERE dtstatdate BETWEEN '20230719' AND '20230725'
    AND mode = 2370
)
SELECT
  (SELECT COUNT(*) FROM yinmi_users) AS yinmi_user_cnt,
  (SELECT COUNT(*) FROM yinmi_users y INNER JOIN qiaoliang_users q ON y.vplayerid = q.vplayerid) AS yinmi_and_qiaoliang_user_cnt,
  (SELECT COUNT(*) FROM yinmi_users y INNER JOIN yinmi_mode_users m ON y.vplayerid = m.vplayerid) AS yinmi_and_yinmi_mode_user_cnt;
```
