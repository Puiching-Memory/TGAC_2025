# SQL生成任务
## 用户问题
统计2024年5月02日-2024年5月02日，日活跃用户的周边休闲模式情况。

活跃日期区间："20250426-20250502"

输出：
日活跃中仅玩QuickMatch模式的玩家数
日活跃中仅玩RushMode模式的玩家数
日活跃中仅玩CombatArena模式的玩家数
日活跃中仅玩以上三个模式不玩其他模式的玩家数
日活跃中仅玩以上三个模式不玩其他模式的玩家周活跃频次
