# SQL生成任务
## 用户问题
统计2024.05.27-2024.6.16每天的乐园高活跃用户和砺刃高活跃用户不重复人数、
乐园高活跃用户和砺刃高活跃用户在当天登录的不重复人数
输出：日期（YYYYMMDD），用户类型（乐园高活、砺刃高活），用户人数，登录人数
## 涉及表名
`dws_jordass_login_di`, `dim_jordass_packet_conf`, `dws_jordass_buttonpress_pre_di`
## 失败案例参考

### 失败案例 1
- **SQL ID**: `sql_98`
- **来源**: CKPT `V7.1_22.09_1108`

**错误SQL:**

```sql
WITH login_users AS (
  SELECT dtstatdate, vplayerid
  FROM dws_jordass_login_di 
  WHERE dtstatdate BETWEEN '20240527' AND '20240616' 
    AND vgameappid IN ('wx', 'qq')
),
leyuan_active AS (
  SELECT dtstatdate, vplayerid
  FROM dws_jordass_buttonpress_pre_di 
  WHERE dtstatdate BETWEEN '20240527' AND '20240616'
    AND vgameappid IN ('wx', 'qq')
    AND buttontype = 'buttonA'
)
SELECT 
  l.dtstatdate,
  '乐园高活' AS 用户类型,
  COUNT(DISTINCT la.vplayerid) AS 用户人数,
  COUNT(DISTINCT CASE WHEN lu.vplayerid IS NOT NULL THEN la.vplayerid END) AS 登录人数
FROM (SELECT DISTINCT dtstatdate FROM login_users) l
LEFT JOIN leyuan_active la ON l.dtstatdate = la.dtstatdate
LEFT JOIN login_users lu ON la.vplayerid = lu.vplayerid AND l.dtstatdate = lu.dtstatdate
GROUP BY l.dtstatdate

UNION ALL

SELECT 
  l.dtstatdate,
  '砺刃高活' AS 用户类型,
  COUNT(DISTINCT lu.vplayerid) AS 用户人数,
  COUNT(DISTINCT lu.vplayerid) AS 登录人数
FROM (SELECT DISTINCT dtstatdate FROM login_users) l
LEFT JOIN login_users lu ON l.dtstatdate = lu.dtstatdate
GROUP BY l.dtstatdate
ORDER BY dtstatdate, 用户类型;
```

> **错误原因**: 结果与预期不匹配
