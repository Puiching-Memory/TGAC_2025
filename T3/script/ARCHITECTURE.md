# 架构对比

## 旧架构（单脚本）

```
┌─────────────────────────────────────────────────────┐
│                   run_datus.py                      │
│                                                     │
│  ┌───────────────────────────────────────────┐    │
│  │  1. 加载数据集                              │    │
│  │     ↓                                       │    │
│  │  2. 读取 schema 和知识库                     │    │
│  │     ↓                                       │    │
│  │  3. 提取 few-shot 示例                       │    │
│  │     ↓                                       │    │
│  │  4. 组装提示词                               │    │
│  │     ↓                                       │    │
│  │  5. 发送 API 请求                            │    │
│  │     ↓                                       │    │
│  │  6. 收集结果                                 │    │
│  │     ↓                                       │    │
│  │  7. 导出结果                                 │    │
│  └───────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────┘

问题：
❌ 每次执行都重新组装提示词
❌ 无法保存和复用提示词
❌ 难以对比不同版本
❌ 职责过于集中
❌ 调试不便
```

```
│  ┌────────────────────┐  │

│  │    ↓               │  │

│  │    ↓               │  │
│  │ 3. 提取 few-shot   │  │
│  │    ↓               │  │
│  │ 4. 组装提示词       │  │
│  │    ↓               │  │
│  │ 5. 保存为文件       │  │
│  └────────────────────┘  │
└──────────────────────────┘
          │
          ↓
┌─────────────────────────────────┐
│  prompts/v1.0.0/                │  中间产物（可复用）
│  ├── SQL001.txt                 │
│  ├── SQL002.txt                 │
│  ├── ...                        │
│  └── metadata.json              │
└─────────────────────────────────┘
          │
          ↓
┌──────────────────────────┐
│  run_datus.py            │  Step 2: 执行阶段（可重复）
│                          │
│  ┌────────────────────┐  │
│  │ 1. 加载提示词文件   │  │
│  │    ↓               │  │

│  │    ↓               │  │

│  │    ↓               │  │

          │

          │
          ↓

│  ┌────────────────────┐  │

│  └────────────────────┘  │
└──────────────────────────┘

优势：
✅ 提示词生成一次，多次使用
✅ 支持版本管理和对比
✅ 职责分离，易于维护
✅ 可直接查看和编辑提示词
✅ 性能优化
```

## 数据流对比

### 旧版本（每次都重新处理）

```
每次执行：
  final_dataset.json ──┐
  schema.json ─────────┤
  common_knowledge.md ─┤──> [组装] ──> [API] ──> result.json
  (动态生成提示词)      │
                       └─> ❌ 无法复用
```

### 新版本（预处理后复用）

```
首次生成：
  final_dataset.json ──┐
  schema.json ─────────┤──> [生成] ──> prompts/v1.0.0/*.txt
  common_knowledge.md ─┘                    │
                                            ↓
                                    ✅ 可以复用
                                            │
多次执行：                                   │
  prompts/v1.0.0/*.txt ←──────────────────┘
          │
          ├──> [执行 1] ──> result_1.json
          ├──> [执行 2] ──> result_2.json
          └──> [执行 3] ──> result_3.json
```

## 性能对比

### 旧版本执行时间

```
单次执行：
┌────────────────────┬──────────┐
│ 加载数据集          │ 5s       │
│ 读取 schema        │ 2s       │
│ 读取知识库          │ 1s       │
│ 组装提示词 (100个)  │ 30s      │
│ API 调用           │ 500s     │
│ 导出结果            │ 2s       │
├────────────────────┼──────────┤
│ 总计               │ 540s     │
└────────────────────┴──────────┘

重复执行：540s × N 次
```

### 新版本执行时间

```
首次生成：
┌────────────────────┬──────────┐
│ 加载数据集          │ 5s       │
│ 读取 schema        │ 2s       │
│ 读取知识库          │ 1s       │
│ 生成提示词文件      │ 30s      │
├────────────────────┼──────────┤
│ 总计               │ 38s      │
└────────────────────┴──────────┘

后续执行：
┌────────────────────┬──────────┐
│ 加载提示词文件      │ 5s       │
│ API 调用           │ 500s     │
│ 导出结果            │ 2s       │
├────────────────────┼──────────┤
│ 总计               │ 507s     │
└────────────────────┴──────────┘

首次：38s + 507s = 545s
重复：507s × (N-1) 次

节省时间（N=3）：
  旧版本：540s × 3 = 1620s
  新版本：545s + 507s × 2 = 1559s
  节省：61s (约 4%)

节省时间（N=10）：
  旧版本：540s × 10 = 5400s
  新版本：545s + 507s × 9 = 5108s
  节省：292s (约 5.4%)
```
